# 04 使用与排障

## 1. 日常命令

```powershell
# 总状态（hook/桥/AstrBot/端口）
powershell -File C:\ProgramData\WeChatBotStack\scripts\status-hook.ps1

# 拉起（幂等）
powershell -File C:\ProgramData\WeChatBotStack\scripts\start-hook-stack.ps1

# 停止桥（加 -IncludeWeChat 连微信一起停）
powershell -File C:\ProgramData\WeChatBotStack\scripts\stop-hook-stack.ps1

# 立刻巡检
powershell -File C:\ProgramData\WeChatBotStack\scripts\watchdog-hook.ps1
```

排查接口：

```powershell
# hook 状态：IsLogin / MessageCallbackPosts / SyncBatchProcessorCalls
Invoke-RestMethod http://127.0.0.1:30001/QueryDB/status | ConvertTo-Json

# 手动测桥（应出现在 hookbridge.log）
$body='{"selfwxid":"wxid_x","msgnumber":1,"sendorrecv":2,"msglist":[{"cmdId":5,"msgtype":1,"fromid":"wxid_x","toid":"wxid_self","room":"","sender":"wxid_x","msg":"bridge self test","msgsvrid":0,"time":1}]}'
Invoke-WebRequest http://127.0.0.1:30002/event -Method Post -ContentType 'application/json' -Body $body
```

日志位置：

| 日志 | 路径 |
|---|---|
| 桥 | `C:\ProgramData\WeChatBotStack\logs\hookbridge.log` |
| 启动/看门狗 | `...\logs\hook-stack.log`、`hook-watchdog.log` |
| AstrBot | `<AstrBot>\data\logs\astrbot.log` |
| 语音样本 | `...\state\voices\*.wav` |

## 2. 启动/重启顺序（重要）

```
AstrBot → 桥 → 微信（带参数）
```

- **桥重启后，hook 的回调线程可能卡死**（`MessageCallbackPosts` 不再增长），表现为"微信正常但机器人不回"。
  处理：**重启微信**（不用换 DLL，重新点登录）。
- 微信重启时如果没带参数（例如被 `-autorun` 拉起），收不到任何消息；用 `start-hook-stack.ps1` 或手动带参数启动。

## 3. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 30001 连不上 | 微信没带参数 / `version.dll` 没放对 | 检查微信目录 `version.dll`、用带参数方式启动 |
| `IsLogin=0` | 未登录 | 微信窗口点登录/扫码 |
| 能发不能收（posts 不涨） | 缺 `RecvType=2` / 回调卡死 | 带参数重启微信；桥重启后也重启微信 |
| `/GetSelfProfile` 500 | 该构建不支持 | 桥用 `config/hook.json` 的 `self_wxid`，忽略 |
| 群消息不理人 | 未 @ 机器人且无唤醒词 | 在群里 @ 机器人，或配置 `wake_prefix` |
| 收图片失败 | 本地无 `.dat` 缓存 | 让对方重发；桥会回退为 `[图片]` |
| 表情包不识别 | CDN 不可达 / 非收藏表情 | 检查网络；系统小表情本来就是文字 |
| 语音不转写 | whisper 未启用 / frida 失败 | 检查 `provider_stt_settings`、`state\voices`、桥日志 |
| 微信双开接错号 | 两个实例只有一个带参数 | 机器人号先带参数启动；个人号后开 |
| 微信升级后全挂 | hook 偏移只对应 4.1.10.27 | 已用 `disable-wechat-update.bat` 拒绝 update 目录写入；仍可能被手动重装/管理员重置 ACL 绕过，需人工确认版本 |
| 桌面弹 PowerShell 窗口 | 计划任务直接调 powershell | 用 `hidden.vbs` 包一层（本包已提供） |

## 4. 微信更新/回滚

- hook 只支持 **4.1.10.27**；升级微信会导致 hook 失效甚至崩溃。
- 回滚：卸载新版本 → 重装 4.1.10.27 → 恢复 `%USERPROFILE%\Documents\xwechat_files` 与 `%APPDATA%\Tencent\xwechat` 备份。

## 5. 备份建议

- 微信数据：`%USERPROFILE%\Documents\xwechat_files`（可 junction 到其他盘）；
- 配置：`C:\ProgramData\WeChatBotStack\config`、AstrBot `data\cmd_config.json`；
- 不要把含 API Key / Token 的配置提交到公开仓库。

## 6. 能力限制（务必知悉）

- 语音**发送**：需要 C++ 逆向（SILK 编码 + CDN 上传 + 语音消息构造），本包未实现；
- **拍一拍**：微信内部系统消息链路，未定位到可挂钩入口，本包未实现；
- 文件/视频发送：hook 没有对应接口；
- 语音接收依赖 frida 扫内存，每条语音多花 1–2 秒，属正常。


## 7. 开机窗口期与消息缓冲（2026-11-23）

- 开机后 AstrBot 启动约需 1–2 分钟，期间微信可能已在线但桥/AstrBot 未就绪；
- 桥现在会在反向 WS 未连接时**缓存事件**（最多 300 条、10 分钟），连上后自动补发；
- 仍然建议：**先桥、后微信**；若重启了桥，务必重启微信重置 hook 回调（否则 posts 不再增长）。
