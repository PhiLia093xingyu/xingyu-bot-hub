# 02 安装步骤

> 目标系统：Windows 10/11 x64。以下路径可自定义，示例沿用作者环境 `C:\ProgramData\WeChatBotStack`。

## 0. 准备

- 微信 4.1.10.27（本包 `wechat/`）；
- Python 3.12（建议用 `uv` 管理）；
- AstrBot 4.28.1（`pip install astrbot==4.28.1`）；
- 可选：VS 2022 Build Tools（只有重新编译 hook 才需要）；
- 可选：NapCat Desktop + SnowLuma + QQ NT（QQ 侧）。

## 1. 安装微信 4.1.10.27 与 hook

1. 把 `wechat\` 整个目录复制到 `C:\Program Files\Tencent\Weixin`（或安装官方 4.1.10.27 到该路径）。
2. 复制 `hook\version.dll` 到微信目录：

   ```powershell
   Copy-Item D:\WeChatBotStack_Distro\hook\version.dll "C:\Program Files\Tencent\Weixin\version.dll" -Force
   ```

3. 在微信目录新建 `wx.ini`（UTF-8，无 BOM）：

   ```ini
   [wx]
   recv_url=http://127.0.0.1:30002/event
   ```

4. **关闭微信自动更新**（设置 → 通用设置 → 取消"自动更新"；或用 hook 自带 `防止微信自动更新` 脚本）。
5. **立即执行一次 `hook\防止微信自动更新\4.x禁止微信自动升级.bat`**：它用 ACL 拒绝当前用户对 `%APPDATA%\Tencent\xwechat\update`、`patch`、`download` 的写权限，使微信无法下载/应用更新（`start-hook-stack.ps1` 每次启动也会自动执行一遍）；
6. 如需双开，可参考 `hook\微信多开` 源码自行编译，或用微信自带多开；
7. 启动微信（必须带参数，见第 5 节），扫码登录机器人账号。

> 说明：`version.dll` 是代理 DLL，微信启动时会自动加载；`StartPort/RecvType/CallBackURL` 三个参数控制 hook 行为。

## 2. 安装 Python 依赖（桥）

```powershell
# 安装 uv（若没有）
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# 创建虚拟环境
uv venv --python 3.12 C:\ProgramData\WeChatBotStack\.venv

# 安装依赖
uv pip install --python C:\ProgramData\WeChatBotStack\.venv\Scripts\python.exe -r D:\WeChatBotStack_Distro\bridge\requirements.txt
```

`requirements.txt` 包含：`websockets`（OneBot WS）、`frida`（语音内存抓取）、`pilk`（SILK 解码）、`psutil`、`Pillow`（表情包转 PNG）。

## 3. 安装 AstrBot 4.28.1

```powershell
# 建议独立目录
uv venv --python 3.12 C:\AstrBot\.venv
uv pip install --python C:\AstrBot\.venv\Scripts\python.exe astrbot==4.28.1

# 首次运行生成配置与 WebUI
C:\AstrBot\.venv\Scripts\astrbot.exe run
```

- WebUI 默认 `http://127.0.0.1:6185`；
- 首次进入按提示设置管理员密码；
- 把本包 `astrbot\plugins\` 下需要的插件复制到 AstrBot 的 `data\plugins\`（可选；插件依赖各自安装）；
- `astrbot\cmd_config.example.json` 仅作字段参考，**不要直接覆盖**运行中的 `data\cmd_config.json`。

## 4. 部署桥

1. 复制 `bridge\` 到 `C:\ProgramData\WeChatBotStack\`，保持目录名 `bridge_hook`：

   ```
   C:\ProgramData\WeChatBotStack\bridge_hook\main.py
   C:\ProgramData\WeChatBotStack\config\hook.json
   C:\ProgramData\WeChatBotStack\scripts\*.ps1
   ```

2. 复制模板并填写：

   ```powershell
   Copy-Item C:\ProgramData\WeChatBotStack\config\hook.example.json C:\ProgramData\WeChatBotStack\config\hook.json
   ```

3. 生成两个随机 Token（WS 客户端 / AstrBot 反连各一个）：

   ```powershell
   -join ((48..57)+(97..102) | Get-Random -Count 64 | % {[char]$_})
   ```

4. 填写 `hook.json`（示例）：

   | 字段 | 说明 |
   |---|---|
   | `hook.self_wxid` | 机器人微信 wxid，见下方"获取 wxid" |
   | `hook.self_nickname` | 机器人昵称 |
   | `onebot.self_id` | 任意正整数（OneBot 机器人 QQ 号占位） |
   | `onebot.ws_server.token` | 客户端连 3002 用的 token（可留空） |
   | `onebot.reverse.url` | AstrBot `wechat` 平台的反向 WS 地址 |
   | `onebot.reverse.token` | AstrBot 平台配置里的 token（必须一致） |

5. **获取 wxid**：登录机器人微信后，打开 `%USERPROFILE%\Documents\xwechat_files\`，里面形如 `wxid_xxx_hash` 的目录就是账号数据目录，`wxid_xxx` 部分即 wxid（多账号时选最近修改的那个）。

## 5. 启动顺序

1. 启动 AstrBot（`astrbot.exe run`）；
2. 启动桥：

   ```powershell
   C:\ProgramData\WeChatBotStack\.venv\Scripts\pythonw.exe C:\ProgramData\WeChatBotStack\bridge_hook\main.py
   ```

3. 启动微信（必须带参数）：

   ```powershell
   & "C:\Program Files\Tencent\Weixin\Weixin.exe" StartPort=30001 RecvType=2 CallBackURL="http://127.0.0.1:30002/event"
   ```

4. 手机扫码登录；
5. 用另一个号给机器人发"测试"，应收到回复。

## 6. 开机自启（可选）

本包 `bridge\scripts` 提供：

- `start-hook-stack.ps1`：检查微信/hook/AstrBot/桥并按需拉起；
- `watchdog-hook.ps1`：每 5 分钟巡检；
- `hidden.vbs`：无窗口启动 PowerShell。

注册计划任务（示例，按实际路径修改）：

```powershell
$root='C:\ProgramData\WeChatBotStack'
$vbs="$root\scripts\hidden.vbs"
$start="$root\scripts\start-hook-stack.ps1"
$watch="$root\scripts\watchdog-hook.ps1"

# 登录后 60 秒拉起
schtasks /Create /TN WeChatBot-Boot /SC ONLOGON /DELAY 0001:00 /TR "wscript.exe \"$vbs\" \"$start\"" /F
# 每 5 分钟巡检
schtasks /Create /TN WeChatBot-Watchdog /SC MINUTE /MO 5 /TR "wscript.exe \"$vbs\" \"$watch\"" /F
```

> 注意：微信自己的开机自启（注册表 Run 下的 `Weixin`，带 `-autorun`）会导致"没有 hook 参数"的实例先启动，必须删除或关闭微信设置里的"开机启动"。

## 7. 验证

```powershell
# hook 是否在线
Invoke-RestMethod http://127.0.0.1:30001/QueryDB/status

# 桥状态
Get-Content C:\ProgramData\WeChatBotStack\state\hook-status.json -Raw

# 端口
Get-NetTCPConnection -State Listen | ? LocalPort -in 30001,30002,3002,24874,24875
```

日志：
- 桥：`C:\ProgramData\WeChatBotStack\logs\hookbridge.log`
- AstrBot：`<AstrBot>\data\logs\astrbot.log`
- hook：`http://127.0.0.1:30001/QueryDB/status` 的计数
