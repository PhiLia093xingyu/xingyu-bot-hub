# 03 配置方法

## 1. AstrBot 平台（wechat）

WebUI → 平台 → 新增平台 → 选 `aiocqhttp`：

| 配置项 | 值 |
|---|---|
| ID | `wechat`（任意，建议固定） |
| 启用 | ✅ |
| 反向 WebSocket 地址 | `ws://127.0.0.1:24875/ws` |
| Token | 与 `bridge/config/hook.json` 的 `onebot.reverse.token` **完全一致** |
| Self ID | 与 `onebot.self_id` 一致 |

> 桥是 WS **客户端**，AstrBot 是服务端：桥主动连 24875。桥的 3002 端口是给其他 OneBot 客户端（可选项）用的，AstrBot 不需要连它。

如果还要 QQ：再新增一个 `aiocqhttp` 平台，反向 WS 端口用 `24874`、Token 与 SnowLuma 配置一致。

## 2. AstrBot 模型服务

WebUI → 服务提供商 → 新增：

- 类型：OpenAI 兼容 / DeepSeek / 其他；
- Base URL：按服务商；
- API Key：`<YOUR_API_KEY>`；
- 模型：如 `deepseek-chat`。

`cmd_config.example.json` 只展示字段结构，**不要**直接覆盖正在使用的配置。

## 3. 语音（接收）

AstrBot 配置：

```json
"provider_stt_settings": {
  "enable": true,
  "provider_id": "whisper-local/small"
}
```

- provider 需为本地 whisper（例如 `whisper-local/small`）或云 ASR；
- 桥收到语音后：内存扫 `#!SILK_V3` → 按 `voicelength` 选候选 → `pilk` 解码 24 kHz wav → OneBot `record` 段；
- AstrBot 转写成功后，LLM 看到的是文字。

> 依赖：`frida`、`pilk`、`psutil` 已包含在 `bridge/requirements.txt`；微信 pid 由启动脚本写入 `state\wechat.pid`。

## 5. 桥配置（`config/hook.json`）

```json
{
  "hook": {
    "api_base": "http://127.0.0.1:30001",
    "callback_host": "127.0.0.1",
    "callback_port": 30002,
    "callback_path": "/event",
    "self_wxid": "<YOUR_WECHAT_WXID>",
    "self_nickname": "<YOUR_WECHAT_NICKNAME>"
  },
  "onebot": {
    "self_id": 100000001,
    "report_self_message": false,
    "ws_server": { "host": "127.0.0.1", "port": 3002, "token": "<WS_TOKEN>" },
    "reverse": { "url": "ws://127.0.0.1:24875/ws", "token": "<ASTRBOT_TOKEN>", "reconnect_seconds": 5 }
  },
  "logging": { "level": "INFO", "file": "logs/hookbridge.log" }
}
```

说明：

- `callback_host` 建议 `127.0.0.1`（不要暴露到公网）；
- `self_wxid` 必须填机器人账号，否则 id 映射与自身消息过滤会异常；
- `report_self_message` 保持 `false`，避免机器人自己的消息再次进 LLM。

## 6. 微信启动参数

```
Weixin.exe StartPort=30001 RecvType=2 CallBackURL="http://127.0.0.1:30002/event"
```

- `RecvType=2` 必须；缺了它 hook 只发不收；
- 参数缺失时 hook 会读 `wx.ini` 的 `recv_url`，但 `RecvType` 仍是默认值，所以**必须用命令行参数**启动。

## 7. 多账号 / 双开

- 只有带 `StartPort=30001` 的实例会被 hook 接管；
- 机器人号先登录（占 30001），个人号后双开即可（第二个实例不带参数，不影响机器人）；
- 删除微信自启项，避免 `-autorun` 的无参实例抢登录：

  ```powershell
  Remove-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'Weixin' -ErrorAction SilentlyContinue
  ```

## 8. 会话隔离（微信/QQ 不串上下文）

`data\cmd_config.json`：

```json
"platform_settings": { "unique_session": true }
```

开启后同一机器人的不同平台/会话各自独立上下文；代价是旧会话 ID 变化，历史上下文不延续。

## 9. 插件

- 本包 `astrbot/plugins/` 为插件源码，复制到 AstrBot 的 `data\plugins\` 后重启；
- 插件配置在 WebUI → 插件管理里逐项填写；
- 涉及平台专属能力的插件（QQ 空间、签到、戳一戳等）在微信平台不生效，属正常。
