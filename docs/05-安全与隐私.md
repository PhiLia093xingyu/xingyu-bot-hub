# 05 安全与隐私

## 本包已剔除的个人信息

打包时删除了以下内容（原环境仍保留，不在压缩包内）：

- 微信聊天数据库、消息缓存、图片/语音/文件、联系人缓存；
- 微信账号标识（wxid）、昵称、手机号、QQ 号；
- AstrBot 的 `data/`（对话记录、人设、插件配置、`cmd_config.json` 真实值、数据库、日志、知识库、工作区）；
- 所有 API Key、平台 Token、OneBot Token、Cookie；
- 桥的 `logs/`、`state/`（包含 wxid、voice 样本、`wechat.pid` 等运行数据）；
- 备份目录与旧版本安装包。

## 本包中仍是"示例/占位"的值

| 位置 | 占位符 |
|---|---|
| `bridge/config/hook.example.json` | `<YOUR_WECHAT_WXID>`、`<YOUR_WECHAT_NICKNAME>`、`<RANDOM_TOKEN_FOR_WS_CLIENTS>`、`<ASTRBOT_WECHAT_PLATFORM_TOKEN>` |
| `astrbot/cmd_config.example.json` | `<YOUR_API_KEY_HERE>`（provider 已清空） |
| `optional-qq/snowluma/onebot.example.json` | `<YOUR_QQ_NUMBER>`、`<ASTRBOT_QQ_PLATFORM_TOKEN>` |

**这些占位符必须替换成你自己的值**，否则无法工作。

## 使用时的安全建议

1. **端口只绑本机**：`hook.api_base`、`callback_host`、`onebot.ws_server.host`、AstrBot 反连地址都用 `127.0.0.1`；不要把 30001/30002/3002/24874/24875 暴露到公网。
2. **Token 全部重新生成**：不要复用任何文档/截图里出现过的 Token；AstrBot 平台 Token 与桥配置必须一致但不要外泄。
3. **API Key 只存在本机**：AstrBot 配置文件权限收紧；不要把 `cmd_config.json` 提交到 Git。
4. **微信账号最小化**：机器人号不要用于支付/重要社交；建议单独设备或虚拟机。
5. **日志脱敏**：桥日志会记录昵称/消息摘要；分享日志前先删敏感内容。
6. **第三方 hook 风险**：`version.dll` 是社区逆向产物，注入微信主进程；来源不明或版本不匹配时不要加载。本包附带的 DLL 对应 4.1.10.27。
7. **合规**：微信/QQ 均为腾讯专有软件，本包仅供本机研究/自用；再分发或商用请自行确认许可与当地法规。

## 若你拿到的是别人的包

- 先检查 `bridge/config/hook.json` 是否含他人 wxid/token；
- 检查 AstrBot `data/` 是否残留他人对话/密钥；
- 所有 Token、API Key 重新生成；
- 不要直接使用来路不明的 `version.dll`。
