# <BOT_NAME>的笔

一支写人，一支写梦。

## 为什么人物总像同一个人扮的

因为大家共用一套万能腔：`眼中闪过一丝`、`嘴角勾起`、`不易察觉`。
形容词写不出人，语料写得出。所以人物卡不给「性格：温柔、内敛」，
只给三样东西：

- `voice` —— 句长、要不要省略主语、绕不绕弯
- `samples` —— 两三句他的原话，让模型照着这个嗓音说
- `ban` —— 他绝不会说的词

生成之后还会验一遍：撞了禁句、或者说出别人的专属口癖（串味），就带着原因重写一次。

## 用法

```
/cast                      看手上几个人
/cast 阿澄 在码头等船       让她就这个情境说一句
/cast 阿澄                 没人问她，她自己开口（从 wants 里随机）
/cast reload               改完 data/cards.json 后重读
```

```
/dream                     用最近聊过的东西当原料
/dream 齿轮 乳白色 雨       指定碎片
/dream list                回顾最近三个梦
```

## 人物卡

`data/cards.json`，可以直接手改：

```json
{
  "name": "阿澄",
  "aliases": ["acheng"],
  "tell": "嗯。",
  "voice": ["句子短，常省略主语", "一句不超过十二个字"],
  "wants": ["想知道明天的风往哪边吹"],
  "fears": ["鱼市早上没有声音"],
  "ban": ["想必", "命运"],
  "samples": ["嗯。风变了。", "网破了，我自己补。"]
}
```

## 梦是怎么拼的

1. 从最近 40 条消息里抽 2~4 字的中文词，洗牌；
2. 掺进上一次梦里的两个碎片——梦会连锁；
3. 交给模型，要求因果断裂、尺度错位、细节具体得像真发生过；
4. 和最近五个梦太像就重掷。

梦存在 `data/dreams.json`，留最近 200 个。
